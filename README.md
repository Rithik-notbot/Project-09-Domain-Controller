# Project 09 - Domain Controller Setup

## Objective
Set up a Windows Server domain controller using Active Directory Domain Services (AD DS).

## Planned Implementation
1. Provision an approved Windows Server EC2 instance.
2. Install Active Directory Domain Services.
3. Promote the server to a domain controller.
4. Configure an Active Directory domain.
5. Create two domain users.
6. Verify the users and domain login.

## Tools
- AWS EC2
- Windows Server
- Active Directory Domain Services
- Remote Desktop Protocol (RDP)
- Terraform

## Security
- Use an approved company VPC and subnet.
- Restrict RDP access to an approved administrator IP.
- Do not commit passwords, private keys, or credentials.

## Status
Documentation started. Deployment and validation pending company approval.
